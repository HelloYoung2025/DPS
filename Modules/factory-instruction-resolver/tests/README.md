Run `python3.12 -m unittest Modules/factory-instruction-resolver/tests/test_instruction_resolver.py` for both process-bound capability authorities, cache-hit re-verification, plain-JSON/direct-constructor/cross-authority/raw-swap attacks, strict canonical wire, quota and expiry pruning, exact write scope, producer direction, exact-major, baseline-fact, Schema-valid stale, quarantine, and controlled races. Run `python3.12 -m unittest Modules/factory-instruction-resolver/tests/test_contracts.py` for the required Draft 2020-12 `instruction.receipt/v2` suite, including real Intake normalized output, exact 30/8/14 parity, all four domain-separated digest positive and negative attacks, impossible February dates without a format checker, expiry equality, real output for all four change kinds, runtime/Schema parity, canonical path attacks, and the frozen v1 Schema hash. Tests use temporary Git repositories and do not modify the DPS worktree; they are local diagnostics until the formal gate records raw evidence.

Contract freeze. `instruction.receipt/v2` is frozen by its owner: `test_contracts.py` pins the v2 Schema SHA-256 against `contracts/provided/instruction.receipt.v2.corpus.json`, validates each committed production receipt with the Schema and `_strict_receipt_v2_object`, recomputes its canonical SHA-256, `receipt_id`, baseline-facts digest, and Intake-domain claims digest with production functions, asserts every negative independently at the Schema layer and the strict-parse layer, and pins canonical JSON bytes with the shared canonicalizer vectors. The undomained receipt digests are frozen as they are; `diff_fingerprint` is pinned only through the receipt digest and ID because its Git preimage is not in the receipt. The Schema-only fixture takes its claims and Manifest ownership digests from the real Intake functions. Any change to the Schema bytes, corpus bytes, digest vectors, or canonicalizer behavior requires a new major under `governance/policies/compatibility-policy.yaml`.
